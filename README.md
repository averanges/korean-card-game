# Хангыль — карточная практика

React + TypeScript + Vite. Запуск: `npm install`, `npm run dev`. Проверки: `npm test`, `npm run build`.

## Текущая версия

36 обычных карт с корейскими словами и 3 магические карты в общей случайно перемешанной колоде. До шести обычных карт в руке; магические приходят дополнительно в отдельную экстра-руку. Начинает владелец младшего козыря, нижняя карта при начальной раздаче обычная. Правила подкидного дурака, без перевода. Контекстные кнопки, индивидуальные переводы, браузерная корейская озвучка (нужен доступный голос устройства).

Бот использует только свою руку, выбирает дешёвую подходящую защиту, бережёт козыри и подкидывает допустимые ранги. Полученную магию применяет автоматически; учебный вопрос предназначен человеку. Во время открытого задания бот приостановлен.

## Магия

По одному экземпляру каждого вида на партию. Карты приходят при раздаче и доборе, не занимают места обычных карт, не используются для обычной атаки и защиты. Они выделены свечением. Нажатие открывает случайный вопрос: корейское слово и четыре уникальных варианта перевода, есть озвучка. После верного ответа карта расходуется в отдельную зону использованной магии. Неверный ответ сжигает карту без эффекта. Отмена до проверки не расходует карту.

- Зеркальный мир: 6 сильнее всех, туз слабее всех до конца партии. Повторный эффект не отменяет инверсию; преимущество козыря сохраняется. Уже закрытые пары не переигрываются.
- Второй шанс: только обычный сброс возвращается в колоду с перемешиванием. Руки, стол и использованная магия не затрагиваются. При пустом сбросе карта расходуется без добавления карт.
- Переворот судьбы: случайная другая масть становится козырем. **Временно — до конца партии**, до согласования длительности.

Временные правила активации: разрешена в свою атаку либо во время защиты, до объявления взятия; обычное действие не расходуется. Добор до 6 учитывает только обычные карты; магия выдаётся дополнительно. Само применение или сгорание магии не вызывает добор. Лимит атаки и победа также зависят только от обычных карт. Эти решения явно указаны в интерфейсе «Правила» и могут быть изменены.

## Расширение

src/engine.ts — игровое состояние, проверка действий и бот; src/words.ts — текущий словарь. Для редактора заменить источник на валидируемый DeckDefinition. Для мультиплеера сервер должен владеть состоянием, вопросами, проверкой ответов и случайностью; клиент получает только свою руку. Нынешняя реализация полностью локальная.

## Оформление и проверки

Оригинальные изображения сохранены в public/assets. См. ASSETS.md. Окно магии: задание слева, оригинальная карта в центре, эффект справа. Фон, верхняя панель, веера и кнопки сохраняют согласованный стиль.

Проверены TypeScript, 12 тестов, в том числе 40 полных симуляций с сохранением всех 39 идентификаторов (карты в колоде, руках, на столе, в сбросе и использованной магии), ошибочный ответ, инверсия без отмены, возврат только сброса, случайная другая козырная масть. В браузере проверены неверный и верный ответы, расход карты и индикатор инверсии. Производственную сборку в текущем окружении ограничивает доступ Windows к родительскому каталогу; локальный Vite работает.

## Активные эффекты

Слева — временные, справа — постоянные. Миниатюры 42×46 px содержат иллюстрацию без текста карты. Наведение, фокус клавиатуры и нажатие открывают описание. Счётчик ограниченного срока показан на миниатюре; постоянный срок обозначен ∞ в подсказке. Сроки: permanent, rounds, turns, event. rounds и turns уменьшаются при завершении розыгрыша (каждый розыгрыш — один переход хода); event завершается по именованному событию. Движок публикует defense-complete, cards-taken и round-end. При истечении пересчитываются модификаторы рангов и козыря. Сейчас mirror и fate постоянные, chance мгновенный.

## Адаптивная рука

Обычная и магическая руки — отдельные компоненты OrdinaryHand и MagicHand. splitHand формирует отдельные категории из игрового снимка, сохраняя прежний контракт движка и вероятности раздачи. Сортировка, геометрия и выбор находятся в handModel.ts; жесты и удержание позиции прокрутки — в useHandScroll.ts.

Сортировка всегда по рангу, затем по масти; эффекты не меняют визуальный порядок. 1–6 карт — симметричный веер до 8°, 7–10 — компактный до 5°, 11+ — горизонтальная лента с неизменным размером карт. Если на узком экране компактный веер не помещается без потери читаемости, он также прокручивается. Колесо переводится в горизонтальную прокрутку, когда странице не требуется вертикальная; горизонтальные жесты и свайпы нативные. Выбранная карта поднимается на 28px, без масштабирования.

Магия: до 3 миниатюр справа; 4+ — раскрываемая стопка. На телефоне при любом количестве — кнопка со счётчиком, отдельно от обычной руки. Панель закрывается без расхода карт, при её открытии бот приостанавливается.

Проверка сценариев: откройте /hand-preview.html у локального сервера. Это отдельный экран с тестовыми картами, не часть игрового потока и не изменение реальной колоды. Проверены 1/3/6/8/10/15/20 обычных, 0/1/2/3/5/8 магических, мобильная ширина 390px, сортировка, группа одного ранга, замена группы другим рангом, снятие выбора, горизонтальная прокрутка, добор и удаление из прокрученной руки, раскрытие мобильной панели. Чистые тесты геометрии покрывают ширины 360/600/900px рабочей области.
