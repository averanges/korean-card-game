# Публикация на Cloudflare Pages

Проект подготовлен как статическое React/Vite-приложение. Сервер приложения, Pages Functions, Wrangler и секретные переменные для текущей игры не нужны. Публикация в аккаунт Cloudflare в рамках подготовки не выполнялась.

## Настройки Pages

| Поле | Значение |
| --- | --- |
| Framework preset | React (Vite) |
| Root directory | Папка, в которой находится package.json |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node.js | `22`, задано в `.nvmrc` |
| Переменные приложения | Не требуются |

Если в репозиторий помещено содержимое папки `hangul-durak`, Root directory оставьте пустым. Если в репозитории сохранена структура рабочего каталога с папкой `outputs/hangul-durak`, укажите `outputs/hangul-durak`. Папка проекта пока не является Git-репозиторием; перед Git integration её нужно добавить в свой репозиторий. Другой вариант — Direct Upload содержимого собранной папки `dist`.

Зависимости и их версии зафиксированы в `package-lock.json`. Для установки с нуля: `npm ci`, затем `npm run build`. В Pages не задавайте `NODE_ENV=production` на этапе установки зависимостей и не используйте `--omit=dev`: TypeScript и Vite нужны при сборке. Установку зависимостей обычно выполняет сама Pages.

## Что проверено

- Команда `npm run build` успешно выполняет проверку TypeScript и сборку Vite. Сборка запускается через переносимый `scripts/build.mjs`, использующий текущий Node и Vite API. Plain ESM-конфигурация загружается напрямую, без отдельной промежуточной сборки файла конфигурации.
- `base: '/'`, `publicDir: 'public'`, результат — `dist`. Публикация рассчитана на корень домена Pages или собственного домена.
- Все используемые изображения доступны по `/assets/...`; проверены существование и регистр имён для Linux. Содержимое `public` копируется в сборку без изменений.
- В исполняемом коде нет зависимости от localhost, Windows-путей, `file://` и локального backend. `127.0.0.1` в команде `npm run dev` относится только к серверу разработки.
- Шрифты системные с резервными вариантами; файлов шрифтов на компьютере разработчика приложение не загружает. Озвучка использует браузерный Speech Synthesis и доступные пользователю голоса, включая Google при наличии.
- Самый большой статический файл — `assets/magic-cards.png`, 2 927 501 байт, меньше лимита Pages 25 MiB на файл.
- `.gitignore` исключает `node_modules`, `dist`, `.env`/`.env.*`, локальные переменные Wrangler, приватные ключи, кэши, журналы и локальные снимки. `.env.example` допускается как шаблон. Существующую историю Git проверить нельзя: репозиторий в папке ещё не инициализирован.
- Правила, интерфейс и анимации в рамках подготовки публикации не изменялись. Предшествующие изменения интерфейса остаются в текущих исходниках; отдельная визуальная проверка адаптивности к задаче публикации не относится.

## Маршруты

Сейчас приложение использует один экран и не требует дополнительных правил маршрутизации. В корне сборки нет `404.html`, поэтому Pages применяет стандартный SPA fallback. Файлы `_redirects` и `_routes.json` не требуются. Проверочные HTML-страницы разработки не входят в production-сборку; публикуйте именно `dist`, а не весь исходный каталог.

## Локальное ограничение среды проверки

В ограниченной среде Windows для запуска самой команды npm использовались временные Node-параметры `--preserve-symlinks --preserve-symlinks-main`. Они не записаны в приложение и не требуются в Cloudflare Pages. Конфигурация Vite также допускает управляемые рабочие каталоги через `resolve.preserveSymlinks`.

## После первой публикации

Откройте адрес Pages по HTTPS и проверьте загрузку изображений, новую партию, озвучку при наличии корейского голоса и обновление страницы. Эти действия на реальном домене можно выполнить после создания проекта Pages.

Документация: [React / Vite](https://developers.cloudflare.com/pages/framework-guides/deploy-a-react-site/), [SPA fallback](https://developers.cloudflare.com/pages/configuration/serving-pages/), [Node.js в сборке](https://developers.cloudflare.com/pages/configuration/build-image/), [лимиты файлов](https://developers.cloudflare.com/pages/platform/limits/).
